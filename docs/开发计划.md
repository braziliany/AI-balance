# AI Balance 开发计划

## 当前版本：v1.1.0

第一版目标是可靠、安全地聚合五个平台的余额信息，并保持与 LPL Scriptable 组件一致的视觉语言。

## P0：发布与真实环境验证

- 将代码发布到 `braziliany/AI-balance`。
- 在 Scriptable 中安装主脚本和设计系统依赖。
- 使用真实 DeepSeek、StepFun、Kimi API Key 验证余额解析。
- 使用 OpenAI Admin Key 验证当月 Costs 汇总及月预算计算。
- 检查小号、中号和大号组件在不同 iPhone 尺寸下的截断情况。
- 验证网络不可用、密钥失效和接口限流时的缓存回退。

## P1：配置与可维护性

- 增加服务显示顺序配置。
- 支持单独隐藏暂时不用的平台。
- 增加刷新频率和缓存时长的图形化配置。
- 增加 Kimi 国际站 `api.moonshot.ai` 区域选择。
- 为 OpenAI 增加组织或项目筛选。
- 显示上次成功更新时间，而不只是本次组件刷新时间。

## P2：额度自动化

- 持续关注 SerpBase 是否提供不计费的账户余额接口。
- 如果官方提供余额接口，将手动 credits 切换为自动查询，并保留手动回退。
- 研究从 SerpBase 导出的账单或使用日志中安全计算剩余额度的可行性。
- 为支持消费明细的平台增加本日、本周或本月变化。

## P3：展示增强

- 增加低余额阈值和警示颜色。
- 增加余额变化趋势和迷你进度条。
- 大号组件显示充值余额、赠送余额、现金余额等明细。
- 支持点击某一平台跳转到对应控制台。
- 增加本地化货币格式和人民币/美元并列展示。

## P4：工程化

- 抽离纯数据解析函数，增加 Node.js 单元测试。
- 为各服务响应准备脱敏 fixture。
- 增加 GitHub Actions 静态检查。
- 增加版本更新日志和 Scriptable 安装器。
- 评估通过远程 manifest 自动更新主脚本与设计系统依赖。
