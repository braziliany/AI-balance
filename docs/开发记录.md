# AI Balance 开发记录

## 项目概况

- 项目名称：AI Balance for Scriptable
- 开发日期：2026-07-29
- 目标仓库：`braziliany/AI-balance`
- 运行环境：iOS Scriptable
- UI 依赖：`LPL-Design-System`

## 需求

制作一个 Scriptable 桌面组件，统一显示以下服务的余额或额度：

- DeepSeek
- StepFun
- OpenAI
- SerpBase MCP
- Kimi

组件视觉需要复用 LPL-scriptable 项目中的 `LPL-Design-System`。

## 调研结论

### DeepSeek

官方提供 `GET /user/balance`，可以读取总余额、充值余额和赠送余额。

### StepFun

官方提供 `GET /v1/accounts`，响应包含当前账户可用余额。

### Kimi

官方提供 `GET /v1/users/me/balance`，可以读取可用余额、现金余额和代金券余额。

### OpenAI

官方没有面向普通 API Key 的“账户余额”接口。组织 Admin Key 可以调用 Costs API 查询本月实际成本。

当前实现允许设置月预算：

- 月预算大于 0：显示“月预算减本月成本”
- 月预算为 0：直接显示本月成本

### SerpBase MCP

官方文档没有公开免费的余额查询接口。为避免组件刷新时产生一次付费搜索，本期采用手动维护剩余 credits 的方式。

## 已实现功能

- 使用 `LPL-Design-System` 渐变背景、色板和排版风格。
- 支持小号、中号和大号 Scriptable 组件。
- DeepSeek、StepFun、OpenAI、Kimi 并行请求。
- SerpBase credits 手动配置。
- 所有 API Key 使用 iOS Keychain 保存。
- 普通设置写入独立 JSON 文件，不包含密钥。
- 余额请求失败时回退到 24 小时内的本地缓存。
- 未配置、接口异常和缓存数据均显示明确状态。
- 默认每 30 分钟刷新。
- 支持深色、浅色和自动主题选项。
- 在 Scriptable App 内运行时提供配置菜单和中号组件预览。

## 已知限制

- OpenAI 需要组织 Admin Key 才能读取 Costs API。
- OpenAI 的“剩余”是用户设置的预算减去本月成本，不是官方账户余额。
- SerpBase credits 需要手动更新。
- 自动主题由设计系统当前接口解析；具体显示效果取决于安装的设计系统版本。

## v1.1.0 UI 修正（2026-07-29）

根据真机截图确认，首版出现了大号组件使用浅色主题、列表集中在顶部且下方留白过多的问题。

修正内容：

- 旧设置首次升级时自动恢复为与 LPL Schedule 一致的深蓝主题。
- 主题设置改为明确选择，不再通过重复点击循环切换。
- 增加“恢复默认 UI”操作。
- 大号组件改为两个重点余额卡片加三条明细的布局。
- README 明确说明推荐使用中号组件，以及 iOS 组件尺寸需要在桌面编辑。

## v1.2.0 一键安装器（2026-07-29）

参照 LPL-scriptable 的安装方式增加 `Installer.js`：

- 首次只需手动复制安装器。
- 自动下载主脚本、设计系统和安装器自身。
- 比较本地与远端语义化版本。
- 从 `CHANGELOG.md` 展示当前版本更新内容。
- 全部资源下载并通过内容标记校验后才开始写入。
- 写入失败时恢复安装前文件，避免半安装状态。
- Keychain、设置 JSON 和余额缓存不在安装资源内，因此更新不会覆盖用户数据。
- 增加 Node.js 安装器单元测试。

## v1.3.0 Codex 额度（2026-07-29）

将 OpenAI 组织月成本替换为 Codex 订阅额度：

- 主值显示 Codex 五小时窗口剩余百分比。
- 副标题显示周额度剩余百分比。
- Access Token 保存到 iOS Keychain，不进入设置文件。
- ChatGPT Account ID 优先从 JWT claims 自动识别，失败时支持手动配置。
- OpenAI 官方目前只公开额度仪表盘和 CLI `/status` 查看方式，没有稳定的第三方额度 API；当前自动查询依赖 Codex 客户端额度接口，因此保留缓存回退并明确标记为实验性集成。
